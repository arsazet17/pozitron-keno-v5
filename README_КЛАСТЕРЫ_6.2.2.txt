ПОЗИТРОН КЕНО v5 / 6.2.2 — КЛАСТЕРЫ

Добавлен отдельный модуль кластеров. Основная логика приложения не заменена.

Кнопки:
🎯 — сборки на следующий тираж;
⏳−1 — сборки через один промежуточный тираж;
⏳−2 — сборки через два промежуточных тиража.

Алгоритм:
1. Вертикаль — число с одного места М в 3–5 последовательных прошлых тиражах.
2. Горизонталь — 3–5 соседних мест М одного прошлого тиража.
3. Для каждой схемы учитывается точная задержка 1–10 тиражей.
4. В модель вошли только схемы, которые были выше случайного уровня и в первой, и в закрытой части исторической базы.
5. Для каждого окна выводятся до трёх вертикалей и трёх горизонталей.
6. Прогноз фиксируется заранее и не переписывается после появления результата.
7. У каждой из трёх кнопок отдельный архив: прогноз, фактические числа, совпадения и полная сборка.

Архив сборок хранится в localStorage и включается в общий экспорт JSON.
